# Sistema de Biblioteca

Sistema de gerenciamento de biblioteca com interface gráfica (Tkinter) e banco de dados SQLite.

## 📋 Funcionalidades

- Cadastro de livros (título e autor)
- Listagem de todos os livros em uma tabela visual
- Empréstimo de livros (com registro de quem pegou emprestado)
- Devolução de livros
- Remoção de livros do acervo
- Persistência de dados em banco SQLite (os dados não se perdem ao fechar o programa)

## 🚀 Como executar

1. Certifique-se de ter o Python instalado (versão 3.6 ou superior). O Tkinter já vem incluso na instalação padrão do Python.
2. Clone este repositório:
```bash
git clone https://github.com/richardbarsotti23-lab/sistema-biblioteca-python.git
```
3. Execute o programa:
```bash
python biblioteca.py
```

## 🛠️ Tecnologias utilizadas

- Python 3
- Tkinter (interface gráfica)
- SQLite (banco de dados)
